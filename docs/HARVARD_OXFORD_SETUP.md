# Harvard-Oxford Atlas Setup (MVP-2)

> Closes audit items **L5** ("HO concrete labels missing") and **D4**
> ("no procedure for downloading and parsing HO labels"). Implements the
> reproducible recipe used by all atlas-driven runs of G4BrainAtlasDose.

## 1. Decision summary

- **Atlas family:** Harvard-Oxford (HO), distributed by FSL (FMRIB,
  University of Oxford), assembled at the Center for Morphometric Analysis
  (CMA), MGH.
- **Cortical file:** `HarvardOxford-cort-maxprob-thr25-1mm.nii.gz`
  (48 regions, label values 1..48).
- **Subcortical file:** `HarvardOxford-sub-maxprob-thr25-1mm.nii.gz`
  (21 compartments, label values 1..21).
- **Threshold:** `thr25` (the de-facto community default; FSLeyes' atlas
  panel and Nilearn's `fetch_atlas_harvard_oxford` both use it).
- **Resolution:** 1 mm (matches the MVP-2 dose grid).
- **Template:** MNI152 asymmetric (Fonov et al. 2011, *NeuroImage*
  54:313, doi:10.1016/j.neuroimage.2010.07.033). Same affine as
  `MNI152_T1_1mm.nii.gz`.
- **Per-atlas CSV:** two files, one per atlas, generated by
  `scripts/build_atlas_labels.py`. Cortical and subcortical labels collide
  (both start at 1), so a single combined CSV would be ambiguous.

## 2. Provenance and citations

The four canonical citations FSL requests when the atlas is used
(documented at <https://fsl.fmrib.ox.ac.uk/fsl/fslwiki/Atlases>):

  labeling system for subdividing the human cerebral cortex on MRI scans
  into gyral based regions of interest." *NeuroImage* 31(3):968.

  cortical gyral parcels.
- **Frazier J. A., Chiu S., Breeze J. L. et al. 2005.** "Structural brain
  magnetic resonance imaging of limbic and thalamic volumes in pediatric
  bipolar disorder." *Am. J. Psychiatry* 162(7):1256.
  doi:10.1176/appi.ajp.162.7.1256. PMID:15994707. — supplies the
  subcortical ROI definitions.
- **Makris N., Goldstein J. M., Kennedy D. et al. 2006.** "Decreased
  volume of left and total anterior insular lobule in schizophrenia."
  *Schizophr. Res.* 83(2-3):155.
  doi:10.1016/j.schres.2005.11.020.
- **Goldstein J. M., Seidman L. J., Makris N. et al. 2007.** "Hypothalamic
  abnormalities in schizophrenia: sex effects and genetic vulnerability."
  *Biol. Psychiatry* 61(8):935. doi:10.1016/j.biopsych.2006.06.027.

Cohort: 37 healthy adults (18-50 years), T1-weighted MRI, manually
delineated by CMA. Inter-rater reliability ICC > 0.85 for major
structures (Caviness et al. 1996, *Cereb. Cortex* 6:726,
doi:10.1093/cercor/6.5.726).

## 4. Why `maxprob-thr25-1mm`

The 4D probabilistic file gives `P(region | voxel) × 100` per region per
voxel; probabilities are not mutually exclusive and may sum to less than
100 (training-cohort variability + unlabeled voxels). The 3D maxprob file
collapses this to a hard parcellation by selecting `argmax` over regions
and writing `argmax + 1` if the maximum exceeds the threshold T (in %),
else 0.

- `thr0`: argmax always assigned. Maximizes coverage but bleeds into low-
  confidence neighbouring tissue.
- **`thr25`: keep voxel only if any region's probability ≥ 25 %.** De-facto
  default (FSLeyes tooltip, Nilearn default). Best trade-off between
  coverage and confidence.
- `thr50`: very conservative. Many voxels become background; ROI volumes
  underestimated by 30-40 %.

For voxel-wise dose aggregation, **`thr25` at 1 mm** is the recommended
choice: it matches the MVP-2 dose grid, it is the published default, and
it leaves no ambiguity to a downstream reader.

## 5. The off-by-one rule (read carefully)

The single most common bug in HO consumers, documented at
<https://fsl.fmrib.ox.ac.uk/fsl/fslwiki/Atlases/Format> and in the
FSLeyes user guide ("Atlases" section):

- The XML attribute `index` is **0-based**: `<label index="0">Frontal Pole</label>`.
- The voxel value in the **summary / maxprob volume** is **`index + 1`**.
- **0 in the maxprob volume is reserved for background.**
- The 4D probabilistic volume uses 0-based indexing along the 4th axis,
  matching the XML.

`scripts/build_atlas_labels.py` validates this invariant: every nonzero
voxel value in the maxprob volume must appear as `index + 1` in the XML;
the script raises `ValueError` otherwise.

records `hemisphere = "Bilateral"` for every cortical row.

in the CSV for completeness, with `hemisphere = "L"` or `"R"` derived
from the name.

## 8. MNI152 / NIfTI invariants

The script enforces (and CI should re-check):

- `nibabel.load(volume).shape == (182, 218, 182)` for 1 mm.
- `np.allclose(volume.affine, MNI152_T1_1mm.affine, atol=1e-6)`.
- `nibabel.aff2axcodes(volume.affine) == ('R', 'A', 'S')` (after FSL's
  standard sform).

Any violation indicates a corrupted or mismatched FSL install — fail
loudly.

## 9. Generating `atlas_labels_cortical.csv` / `atlas_labels_subcortical.csv`

```bash
# Auto-detect FSLDIR
python scripts/build_atlas_labels.py --output-dir configs/atlases

# Or pin an install
python scripts/build_atlas_labels.py \
    --fsldir /usr/local/fsl \
    --output-dir configs/atlases

# Or pick a different threshold
python scripts/build_atlas_labels.py \
    --variant maxprob-thr50-1mm \
    --output-dir configs/atlases
```

Output, conforming to `docs/ATLAS_LABELS_SCHEMA.md`:

```
configs/atlases/atlas_labels_cortical.csv      # 48 rows
configs/atlases/atlas_labels_subcortical.csv   # 21 rows
```

Schema (`label, name, hemisphere, source`):

```csv
label,name,hemisphere,source
1,Frontal Pole,Bilateral,"Harvard-Oxford (FSL); Center for Morphometric Analysis, MGH"
2,Insular Cortex,Bilateral,"Harvard-Oxford (FSL); Center for Morphometric Analysis, MGH"
...
```

The script:

1. Parses `HarvardOxford-Cortical.xml` and `HarvardOxford-Subcortical.xml`.
2. Loads the corresponding maxprob NIfTI.
3. Validates that `set(np.unique(vol)) - {0}` is a subset of the XML
   labels.
4. Writes the two CSVs with hemisphere derived from the name (`Left ` /
   `Right ` / fallback `Bilateral`).
5. Prints a one-line summary per atlas to stdout.

## 11. Known limitations

1. Cohort is 37 healthy North-American adults (18-50, predominantly
   right-handed). Generalisation to pediatric, geriatric, atrophic, or
   non-Caucasian-majority populations is *limited and unmeasured*.
2. Cortical parcellation is gyral-coarse (48 regions). Finer atlases
   exist (Destrieux 2010, Glasser MMP 2016, Schaefer 2018) but lack HO's
   gold-standard CMA manual delineation.
3. `thr25` ROIs typically cover ~70-80 % of the corresponding manual
   labels; report ROI coverage in the QC.
4. Subcortical labels {1,2,3,12,13,14} are tissue/CSF compartments,
   *not* anatomical ROIs. Downstream code must filter them when
   producing region-by-region tables.
5. Inter-rater reliability is high for major structures but unmeasured
   for some smaller cortical subdivisions.
